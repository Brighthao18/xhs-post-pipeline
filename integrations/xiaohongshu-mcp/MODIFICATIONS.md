# 小红书后端修改说明

本目录是固定上游版本的源码覆盖层，不是完整上游仓库。原始上游来自 `https://github.com/xpzouying/xiaohongshu-mcp.git`，提交 `a5c8f7799980ba1fdd501999843eb2d17e4c9a9f`，保留 Apache-2.0 许可。文件清单与 SHA-256 见 `upstream.json`。

相对上游的修改包括：

- 独立登录状态与 Cookie 路径、回环监听及服务令牌授权。
- 实际账号身份、编辑器预飞、图片上传证据、AI 声明与单次提交意图。
- 管理页状态证据和提交后回查候选，结果不明时禁止自动再次提交。
- 安全的错误诊断、私有记录路径控制和离线协议测试。
- 嵌套 `headless_browser` 的原生 Chrome 兼容路径；该模块另保留 MIT 许可与 `PATCH.md`。
- 公开发行移除测试中的个人账号编号，改为显式离线夹具标识，并增加修改标记。

本项目未把这些上游衍生文件改为 MIT，也不分发登录状态、二进制、上游完整历史、缓存或实际账号证据。修改标记适用于覆盖层源码；其他未修改文件仍由固定版本上游提供。
