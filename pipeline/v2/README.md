# 本地工作流模块

安装、无账号示例和公开范围见根目录 [README](../../README.md)。

使用 `xhs-pipeline init --workspace .` 创建私有配置，然后用 `--config <文件>` 执行 `doctor`、`status` 或工作流命令。相对路径和字体见 [配置说明](../../docs/configuration.md)，阶段与租约见 [工作流说明](../../docs/workflow.md)。

模块保存来源、版本、素材、图像意图、审阅与提交账本。创作、事实核查、真实图片生成和实际平台回查仍由执行者完成。新配置关闭发布，测试夹具不得授权真实提交。

原生产部署的账号、订阅、时间记录、验收素材和回退信息属于私有运行记录，保存在本机的任务备份中，不纳入公开文档。
