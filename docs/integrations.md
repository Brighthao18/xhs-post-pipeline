# 可选服务接入

离线卡片和本地账本只依赖 Python 与 Pillow。联网发现、原生 Image 与账号提交需要额外能力，均不属于默认启动动作。

| 能力 | 接入方式 | 当前范围 |
| --- | --- | --- |
| RSS / Atom / JSON Feed | `pipeline.v2.sources` 标准库读取 | 除 UTF-8/UTF-16 与单字节编码外，也读取 GB2312、GBK、GB18030、Big5；正文仍需单独取得并核查 |
| WeRSS | `integrations/werss/` 本地容器引导与严格刷新端点 | WeRead 模式仅验证最新一篇，不保证历史补抓或多篇覆盖 |
| 原生 Image | 代理实际调用 Image，登记本地结果 | 脚本只记录协议，不提供模型调用或计费服务 |
| 小红书发布 | `integrations/xiaohongshu-mcp/` 固定上游版本和源码补丁 | 需用户独立登录、绑定、编辑器及提交后回查 |

WeRSS 与发布服务的端口只应绑定本机回环地址。客户端拒绝携带凭据向任意公网后端或重定向地址发送请求。原版服务不一定具备本项目需要的 `/xhs-integration/*` 端点，不能仅凭健康检查成功判断发布能力兼容。

小红书后端的构建与离线测试见[后端说明](../integrations/xiaohongshu-mcp/README.md)；WeRSS 的隔离部署见[采集服务说明](../integrations/werss/README.md)。此发行包含适配代码及来源版本信息，不包含容器镜像、可执行程序、Go 缓存、系统浏览器、账号密码或 Cookie。

真实上游访问、平台界面和频率限制可能变化。首次发现、实际提交与唯一笔记回查需要在自己的账号与权限范围内验收。本地模拟测试只验证协议和错误处理，不声明具备平台官方 API 或服务保证。
